Fixen is a Haskell library and executable. You can use it in two ways: as a standalone compiler tool installed on your system, or as a dependency in your Haskell project. Both approaches are covered below.

## Prerequisites

Before installing Fixen, ensure you have the following installed. We recommend using [GHCup](https://www.haskell.org/ghcup/) for managing GHC and cabal versions.

<Tabs syncKey="prerequisites">
  <TabItem label="GHC">
    Fixen requires **GHC 9.12.2** (base 4.21.0.0).

    ```ansi
    [35m~ $[0m [31m[1m[4mghc --version[0m
    The Glorious Glasgow Haskell Compilation System, version 9.12.2
    ```
  </TabItem>

  <TabItem label="Cabal">
    Fixen requires **Cabal 3.16+**.

    ```ansi

    cabal-install version 3.16.1.0

    ```
  </TabItem>

  <TabItem label="Git">

## Approach 1: Standalone Installation

Install Fixen as a standalone command-line tool. After installation, you can compile `.fix` files from anywhere on your system.

:::steps
1. Clone the Fixen repository

   ```ansi
   [35m~ $[0m [31m[1m[4mgit clone https://github.com/plilab/fixen.git[0m
   [35m~ $[0m [31m[1m[4mcd fixen[0m
   ```

2. Build and install the `fixen` executable

   ```ansi
   [35m~ $[0m [31m[1m[4mcabal install fixen[0m
   ```

   This installs the `fixen` binary to your Cabal user binary directory (typically `~/.cabal/bin`). Make sure this directory is in your `PATH`.

3. Verify the installation

   ```ansi
   [35m~ $[0m [31m[1m[4mfixen --help[0m
   ```

   You should see the help output describing the available options.
:::

Once installed, you can compile Fixen programs with:

```ansi
[35m~ $[0m [31m[1m[4mfixen --output [32mOutput.hs[31m [32mInput.fix[0m
```

## Approach 2: Project Dependency

Use Fixen as a dependency in your Haskell project. This approach is useful when you want to integrate Fixen-generated code directly into a larger Haskell project.

:::steps
1. Add `fixen` to your project's `.cabal` file

   In the `build-depends` section of your library or executable, add:

   ```txt
   build-depends:
     fixen
   ```

   If your project uses a `cabal.project` file with a local path constraint, add:

   ```txt
   source-repository-package
     type:             git
     location:         https://github.com/plilab/fixen.git
     tag:              <version-or-branch>
   ```

2. Build your project

   ```ansi
   [35m~ $[0m [31m[1m[4mcabal build[0m
   ```

   Cabal will fetch and build Fixen alongside your project.

3. Use the Fixen compiler in your build pipeline

   You can invoke the Fixen compiler as part of your project's build process (e.g., in a `build-tool-depends` section or a custom build script) to generate Haskell source from `.fix` files before compiling the rest of your project.
:::

:::tip
If you are developing Fixen itself and want to use the local source, you can run:

```ansi
[35m~ $[0m [31m[1m[4mcabal run fixen -- --output [32mOutput.hs[31m [32mInput.fix[0m
```

This builds and runs the Fixen compiler from source without installing it globally.
:::
